# 🎓 React + TypeScript: Higher-Order Components

Добро пожаловать в проект, созданный в рамках курса Нетологии по изучению **React** и **Higher-Order Components (HOC)** с использованием **TypeScript**! Этот проект включает 9 задач, каждая из которых демонстрирует различные аспекты разработки пользовательского интерфейса с использованием компонентов React, HOC, строгой типизации и стилизации CSS. Проект развёрнут на GitHub Pages и доступен для просмотра.
